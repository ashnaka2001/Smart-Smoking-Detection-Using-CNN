# 🚭 Smart Smoking Detection Using CNN
An AI-powered real-time smoking detection system built using Streamlit, TensorFlow/Keras, and OpenCV. This project promotes public health and safety by detecting smoking behavior from both uploaded images and live webcam streams.

# 🔑 Key Features
✅ Accurate Predictions using a trained Convolutional Neural Network (CNN)
📷 Dual Mode Input: Supports both image upload and live webcam detection
🚨 Real-Time Alerts with optional sound notifications for smoking events
🌐 Interactive Web Interface built with Streamlit
🧠 Lightweight & Fast, suitable for real-time applications
🛠️ Modular Code Structure for easy customization and model upgrades

# ⚙️ Tech Stack
Python
TensorFlow / Keras – for model training and inference
OpenCV – for webcam feed and image processing
Streamlit – for building the web app
NumPy, PIL – for data handling and image manipulation

# 📌 Use Cases
Airport and public space monitoring
Smoking policy enforcement in offices or campuses
Health analytics research projects
