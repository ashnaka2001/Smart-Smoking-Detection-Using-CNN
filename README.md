# Smart-Smoking-Detection-Using-CNN
An AI-powered real-time smoking detection system built using Streamlit, TensorFlow/Keras, and OpenCV. This project aims to enhance public health and safety by identifying smoking behavior from both uploaded images and live webcam feeds.

# 🔍 Key Features

✅ Accurate Predictions using a trained Convolutional Neural Network (CNN) model

📷 Dual Mode Input: Supports Image Upload and Live Webcam Detection

🚨 Real-Time Alerts with optional sound notifications for smoking events

🌐 Custom UI built with Streamlit for an intuitive, user-friendly experience

⚙️ Technologies Used: Streamlit, OpenCV, NumPy, Keras, PIL
